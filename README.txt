My chosen topic for this project is screen time. I wanted to see if the number of notifications a user receives reflects their screen time. In this project, I collected data using the Digital Wellbeing app, which lets me track the number of notifications I receive, how many times I unlock my phone, and my total screen time for the day. I have 2 categories: Secure and General screen times. I separated the data to show what takes up most of my time. The data can be found in the CSV file and there is also a key which explains the different screen time categories.
